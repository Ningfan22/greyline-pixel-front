# 灰线 v216：断油停车、观测记录与坦克火控

## 行为

- 真正燃油归零的地面车辆保持原位，任何进退或回补命令都不能使它继续行驶；补给组或空投箱送到后才能恢复。车辆原来的细补给线分为弹药、燃油两个短段，断油显示“断油”；菜单提供原地待命、等待送补给。
- 修正本地待命锚点回位曾一次性移动的路径，回位按实际速度、时间和燃油结算。
- 地面步兵观察范围高于本身武器射程；轻坦、主战坦克、重坦自身观察为440、450、420，小于主炮射程，友军观察可以引导主炮。
- 坦克主炮新目标或机动后需要停车稳定、测距瞄准1.2秒，炮管逐步对准才开火。装填与瞄准可同时进行，同一目标不逐炮重复测距；机枪独立交战。
- RPG发射手100基础伤、反甲×2.4、穿透3级装甲，护卫步枪不跟着提高。
- 双方敌情记录只保存最后真正观察的兵种、位置。地图区分步兵、坦克、火炮、车辆，隐藏后保持最后位置，重新观测才跳到新位置；隐藏单位的移动、死亡不会偷偷改写记录。实地确认空地后清除，过期报告不再强制挡住推进。
- 步兵重火力后撤不再把视野暂时消失当成安全，确认清空或获得真实反甲支援后才恢复推进；普通推进也尊重尚未清空的近处观测记录，减少视野边缘折返。
