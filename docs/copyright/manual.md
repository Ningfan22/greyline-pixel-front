# 灰线像素前线游戏软件 说明书

## 一、软件概述

**软件名称**：灰线像素前线游戏软件
**软件简称**：像素前线
**版本号**：V1.0
**软件分类**：游戏软件（移动端小游戏）

灰线像素前线是一款现代战争题材的像素风格即时策略卡牌对战游戏。玩家通过组建卡牌卡组、部署作战单位、指挥小队行动，在像素化的现代战场上与AI对手进行实时对抗。游戏融合了卡牌收集、卡组构建、即时战略和战役剧情等多种玩法。

## 二、运行环境

- **运行平台**：抖音小游戏（兼容Android/iOS）
- **屏幕要求**：横屏（大厅、商店、组卡、战斗均为横屏）
- **网络要求**：需要联网（美术资源从CDN加载）
- **存储空间**：主包约4MB，运行时缓存约30MB

## 三、功能模块

### 3.1 大厅模块

- 显示玩家昵称、军衔、资源数量
- 快速匹配：随机地图、随机对手、标准难度
- 战役模式：按章节推进的剧情关卡，含难度选择
- 卡组管理：创建、编辑、删除、重命名卡组
- 商店入口：购买卡包和专属卡牌
- 作战手册：查看游戏规则和卡牌说明

### 3.2 卡组构建模块

- 浏览全部卡牌图鉴，按费用、类型、身份筛选
- 从卡牌池选择卡牌加入当前卡组
- 查看卡组统计曲线（费用分布、单位/指令/建筑比例）
- 支持多套卡组保存和切换
- 卡组校验：最少20张，同名卡最多3张

### 3.3 商店模块

- 购买基础卡包（随机5张卡牌）
- 购买专属卡牌（直接获得指定卡牌）
- 显示资源余额和购买确认

### 3.4 战斗模块

- **实时战场**：横向卷轴像素战场，支持拖拽移动视野
- **卡牌出牌**：从手牌拖拽卡牌到战场部署单位或释放指令
- **小队指挥**：点击已部署单位选中，通过浮动菜单下达移动、攻击、驻守、撤退等指令
- **能量系统**：能量随时间增长，用于支付卡牌费用
- **抽牌系统**：消耗能量从牌库抽牌，手牌有上限
- **小地图**：显示战场全貌和单位位置
- **暂停/继续**：支持中途暂停，含音频设置
- **战斗结算**：显示胜负结果和战役进度

### 3.5 卡牌系统

游戏包含多种卡牌类型：

- **单位卡**：步兵、海军陆战队、特警、民兵、特种兵等身份，各有不同属性和特殊技能
- **指令卡**：空袭、炮击、医疗、维修等战场指令
- **建筑卡**：防御工事、掩体等固定设施
- **载具卡**：坦克、装甲车、直升机等重型装备
- **专属卡**：通过商店购买的特殊卡牌

每张卡牌具有费用、生命值、攻击力、射程、移动速度等属性，部分卡牌拥有主动或被动技能。

### 3.6 战役模式

- 多章节剧情战役，每章含多个关卡
- 难度选择：标准/困难/极难，影响AI资源和智能
- 战役对话系统：关卡前后的剧情对话
- 难度奖励：完成高难度获得额外奖励

### 3.7 音频系统

- 背景音乐：搜索/大厅BGM
- 战斗音效：步枪、狙击、爆炸、引擎、脚步等
- 音频设置：总开关、音效开关、音乐开关
- 音频中断处理：来电/闹钟时自动暂停

## 四、技术架构

### 4.1 前端框架

- **UI层**：纯Canvas渲染的自研UI框架，包含Widget组件体系（Button、Slider、Toggle、ScrollList等）
- **游戏引擎**：自研回合制/即时制混合游戏引擎，60Hz固定步长更新
- **渲染管线**：Canvas 2D API，像素画风格图集渲染
- **动画系统**：帧动画、补间动画、粒子特效

### 4.2 平台适配

- **抖音小游戏适配层**：通过Platform Adapter模式，将Web API（document、Image、localStorage、fetch、AudioContext）映射到抖音小游戏API（tt.createCanvas、tt.createImage、tt.getStorageSync等）
- **资源管理**：美术资源（WebP格式图集）从CDN动态加载，音频文件打包在主包内
- **字体加载**：通过tt.loadFont加载像素字体
- **生命周期**：处理onHide/onShow/onAudioInterruption等小游戏生命周期事件

### 4.3 数据存储

- 本地存储：玩家数据、卡组配置、游戏进度通过tt.setStorageSync持久化
- 卡牌数据：静态卡牌定义内嵌于代码中
- 战役进度：本地存储记录章节完成状态

## 五、操作说明

### 5.1 基本操作

- **点击**：选择单位、确认按钮、查看卡牌详情
- **拖拽**：移动战场视野、拖拽卡牌出牌
- **长按**：长按卡牌查看大图详情

### 5.2 战斗流程

1. 在大厅选择"快速匹配"或"战役模式"进入战斗
2. 等待资源加载完成后点击"开始作战"
3. 能量随时间增长，点击底部卡牌按钮抽牌
4. 拖拽手牌到战场部署单位
5. 点击已部署单位，通过浮动菜单下达指令
6. 摧毁敌方基地或达成战役目标获胜
7. 战斗中可随时暂停，调整音频设置

### 5.3 卡组构建

1. 在大厅点击"卡组"进入组卡界面
2. 从左侧卡牌池选择卡牌加入卡组
3. 点击卡组中的卡牌可移除
4. 满足20张最低要求后可保存
5. 可创建多套卡组，在大厅切换
