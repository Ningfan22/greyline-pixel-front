## 六、申请流程提示

1. 登录 register.ccopyright.com.cn 注册账号并完成实名认证
2. 选择"计算机软件著作权登记"
3. 按上表填写软件基本信息和著作权人信息
4. 上传源程序文档（source-code.txt 转 PDF，每页确保≥50行）
5. 上传软件说明书（manual.md 转 PDF）
6. 在线提交并等待受理通知书
7. 按通知缴纳费用（目前免收登记费，⚠️ 以官网最新政策为准）
8. 等待审查（通常30-60个工作日）
9. 审查通过后获得《计算机软件著作权登记证书》

## 注意事项

- 源代码文档每页必须≥50行（不含空行和注释行可适当放宽，但建议含注释也≥50行）
- 页眉需标注软件名称和版本号
- 源代码中不得包含第三方版权声明（如有MIT/Apache等开源依赖，需在说明书中声明）
- 说明书需包含软件功能介绍、技术架构、操作说明、界面截图（⚠️ 建议补充游戏截图）
