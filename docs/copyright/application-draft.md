## 六、申请流程提示

1. 从 https://www.ccopyright.com.cn/ 的“软件登记”入口进入，登录账号并完成实名认证
2. 选择"计算机软件著作权登记"
3. 按上表填写软件基本信息和著作权人信息
4. 上传源程序文档（output/pdf/source-code.pdf）
5. 上传软件说明书（output/pdf/manual.pdf）
6. 在线提交并等待受理通知书
7. 按通知缴纳费用（目前免收登记费，⚠️ 以官网最新政策为准）
8. 等待审查，受理和补正安排以登记系统通知为准
9. 审查通过后获得《计算机软件著作权登记证书》

## 注意事项

- 一般交存要求前后各连续30页，不足60页时提交全部；通常源程序每页不少于50行，文档每页不少于30行。依照登记系统当次要求核对最后页及含图页等情形。
- 页眉需标注软件名称和版本号
- 保留依法及许可证要求保留的第三方版权声明，不要删除声明来制造原创假象；生成器仅提取本项目小游戏源码，不打包 node_modules。
- 说明书包含软件功能介绍、技术架构与操作说明；后续如需补充截图，应从实际运行版本截取。
- 依据：[国家版权局《计算机软件著作权登记办法》第十条](https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/t20241015_869486.html)。主体与权属信息未确认前，不把草稿视为已提交申请。
