# 灰线 v217：炮兵检查与自动跟随

点击炮兵打开菜单不再隐式下达永久警戒，也不打断正在执行的进退或补给任务。野战炮、反坦克炮、防空炮以及自行火箭炮、迫击炮车的菜单新增“自动跟随”，可解除主动下达的警戒并恢复原有战线跟随。

手动前进、后退完成一次转移后恢复自动控制；牵引炮重新架设，继续自主交战。推进被已观察到的近处敌军安全线限制时，也结束转移并架炮，避免持续推进导致无法射击。直射炮不再因曾经开过火而永久停止跟随，保持有效射击阵位，交战结束后等待6秒再跟随前移的战线。普通步兵和车辆的点击停止行为保持原有规则。

## 验证

188项行为检查、3项图集检查通过，类型检查、正式构建通过。新检查覆盖双方8种炮兵/自行火力单位的重复点击、主动警戒与恢复跟随、转移完成、观察接敌与实际射击、补给任务保持。旧坦克炮口场景加入真实友军观察，并等待正常1.2秒瞄准；旧补给菜单文本检查适配断油车辆的既有条件文案。两个旧场景在修改前v216基线也失败，本次未为通过它们改动战斗规则。

正式构建浏览器检查：点击并关闭菜单后，炮兵1秒移动22px，11秒移动239px，仍为自动跟随；手动后退后31秒完成转移并恢复自动；己方战线前移500px后，炮兵41秒前移170px，无需再发指令。主动警戒后51秒、52秒位置保持170px；选“自动跟随”后62秒达到394px。浏览器无错误日志。
