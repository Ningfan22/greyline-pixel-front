# v215 · 制导弹与房屋遮挡

陶式等制导武器此前同时受直射瞄准检查和房屋碰撞影响：前线已经看到敌方装甲，发射车仍等待无遮挡直线，或导弹被中间房屋吃掉。

现在使用制导弹专用射击检查和屋顶航路。弹体从原来的发射口出发，越过沿途房屋后追踪已观察目标；标枪保留先爬升再攻顶的动作。制导武器不会为了清墙把主弹改射房屋。这里是游戏中的景物遮挡规则，房屋不会被视为无穷深的横向屏障。

- 视野、烟幕、最小/最大射程、雷达干扰、装填和目标类别限制继续生效。
- 地面制导弹仍会撞上土地、树干和金属残骸；普通火箭、炮弹与步枪保留各自原有遮挡规则。
- 制导弹燃料耗尽只在当前位置产生视觉爆炸，不会远程伤害未抵达目标。
- 武器检查页新增陶式、标枪越屋交战，以及半秒推进按钮；清理测试场景继承的旧景物记忆，让可见房屋与当前碰撞结构一致。

验证：114 项交战、枪管、视野和移动回归检查通过，3 项预烘焙美术一致性检查通过，类型检查与 Pages 构建通过。新增检查覆盖双方、单屋/连续两屋、屋顶物理航路、实际装甲伤害、普通弹药遮挡、土坡、隐藏目标、烟幕与燃料耗尽。浏览器使用正式构建运行真实交战：陶式单发越屋，目标生命由 10000 降至 9700.5。
