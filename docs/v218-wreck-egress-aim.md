# 灰线 v218：连续残骸堵塞与坦克测距

修正射击位置规划和实际敌我间距规则互相冲突的问题：步兵不再选择敌人另一侧无法到达的射击位置，规划位置同时检查实际可达性。困在报废车辆实体轮廓内、无法射击的步兵会用正常步行动画撤到轮廓外，再恢复交战；新敌情堵住出口时重新评估。保持地形、陡坎、实体弹道、阵地待命和补给待命规则。

坦克把近处普通步枪兵与真正反坦克威胁区分开，普通步枪兵不再让坦克永远停在残骸后的无效射击线。实际反坦克威胁继续触发安全退让。步兵撤离步枪射程、停止受击并完成8秒整顿后，会重新尝试推进；视野内的无支援坦克仍要求反甲支援或确认安全，掩体内仍在射程中的士兵不会因此放弃掩体。

坦克主炮首次观察测距延长到3秒，移动车体、换目标或持续失去观察后重新瞄准。装填期间可以持续观察同一目标，机枪仍可自主交战。瞄准期间显示“测距瞄准”。

## 验证

202项针对性行为检查、3项图集检查通过，类型检查、正式构建通过。288单位、600帧的密集战斗保持数值正常。针对双方镜像检查三类坦克完整3秒真实首发、移动重新瞄准、单辆和连续残骸、实际逃生乘员、带武器的残骸内守兵、明确待命、失去视野后的步枪整顿推进以及无支援坦克安全撤退。

正式构建浏览器检查：坦克2.5秒仍为0发、移动0px；3.5秒发射1发，敌重坦生命从10000降至9610。三辆连续残骸与12名步兵，20秒守兵生命降至0，40秒坦克前进689px、代表步兵前进570px。实际坦克报废/乘员逃生场景，30.3秒敌方幸存兵0，40.3秒坦克前进918px。浏览器无错误日志。

旧v203的双步兵班组歼灭并保持8人生还断言、旧v210的弹坑掩护生存断言，在修改前v217基线也失败；本次没有通过增加生命或取消敌军火力来迎合这些旧平衡断言。v203静态高生命目标原地不动的时间假设改为45秒，以适应守兵现在实际离开残骸、移动交战。检查保留原有命中、伤害和实际射击要求。
