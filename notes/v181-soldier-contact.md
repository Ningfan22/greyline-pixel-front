# v181 — 连续转身、坡地落脚和伤员拖拽

用户要求“上线吧”。本次沿用原 GitHub Pages 网址，发布已验证的动作修复，不删减已有功能，不改变卡牌费用或武器伤害。全员动画检查目标仍在继续，网页版发布不等于抖音上架。

## 修改

- 固定同一身体的身份、像素比例、骨长和前后腿层级。转身重接上一帧世界坐标中的身体，腿部继续接入步态，不整张镜像瞬移；转身与卧倒/起身同时发生时，连续展开角度，避免跨越旋转边界突然折腿。
- 每只脚分别采样坡地高度，髋部跟随地形，平滑处理坑沿；不改变射击原点。下坡脚端允许低于身体基准，画布添加透明下边距而非缩小人物，活体与抛飞尸体都保留原锚点。
- 爆炸抛飞落地后接续旋转并逐渐停稳，不立即跳到最终角度。
- 拖拽者先走到伤员靠近己方的一侧，再让双方保持相同位移；修复从另一侧接近时伤员瞬移约 33 像素的问题。不能移动的野战医疗站不再接受拖拽任务。
- 网页与原生小游戏同步 v181；保留旧哈希资源及版权申请材料。
