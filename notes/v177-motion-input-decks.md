# v177：举枪步态、Canvas 操作与新卡实际行为修正

基线：`b8a435f9cbf3eb1fcc0e1fca99fce39e06d29b61`（main）。本轮不删减玩法，不重置真实玩家存档。

## 已修正

- 举枪/射击时移动：静态全身巡逻举枪图不再覆盖正在播放的本兵种八帧步态；站定才使用静态举枪/开火图。补给和拾取的残留动作计时也不能冻结移动中的腿。
- 保留黄制服海军陆战队、蓝制服武装警察、步兵、民兵各自身份；低姿态、后退、换弹等状态有专门回归断言。没有重新绘制或替换全部历史步态图集，不能据此声称所有美术帧间问题已消失。
- 触摸取消、切后台、页面跳转、弹窗切换不会被当作松手出牌；按钮须在内部有效松手才触发，同一控件不能被第二根手指重复接管。
- 拖牌只允许松到战场，顶栏不再算合法投放区；竖向拖动战场不会误判为点地出牌；暂停清除正在进行的卡牌手势。
- 实时刷新保留同一张手牌和同一条队伍指令按钮的对象，避免按住时刷新导致失效；手牌始终位于暂停、结算和横屏提示下层。
- 卡组确认弹窗与详情弹窗的背景改在文字之前绘制；离开脏卡组先确认，删除卡组清除撤销历史。
- 初始编队使用真正已拥有的20张牌，避免重启后裁成18张；导入存档过滤非法/内部卡和超额牌，重复卡组槽 ID 会重新分配，避免一次编辑/删除多套卡组。
- 喷火组、轻迫击炮组明确为一名专职武器手加一名步枪护卫，不再给两人复制同一重武器；卡牌说明与成员实际射击数据同步。
- 侦察车保持地面移动并使用自卫机枪，不再进入侦察无人机悬空且停止开火的分支。
- 多管火箭炮按三发、每发16伤害、0.35秒间隔、之后7.5秒装填工作，使用火箭与曲射轨迹；不再错误继承装甲。
- 喷火使用独立火焰弹道与短程范围灼伤，不套用普通步枪/高爆弹坑；喷火坦克过高伤害下调为每0.4秒12、对步兵1.5倍，对甲0.08倍。
- 图像生成补齐五种新单位的独立卡图，见 `v177-card-art.md`；132份既有 WebP 美术同步到小游戏 CDN 目录，新增同步脚本，修复卡包相对路径没有走 CDN 的问题。
- 小游戏原生图片对象与可构造音频上下文适配修正；存档在适配层就绪后读入；适配层先于会在导入时创建画布的渲染模块初始化。

## 复验入口

```sh
node scripts/sync-minigame-webp.mjs
node node_modules/typescript/bin/tsc --noEmit
node node_modules/vite/bin/vite.js build --config vite.pages.config.ts
node node_modules/vite/bin/vite.js build --config minigame/vite.config.ts
node --experimental-strip-types --loader ./ts-resolve.mjs --test tests/v177-*.test.mjs
```

使用 Node 24；渲染/启动测试需能解析 `@napi-rs/canvas`（本次通过运行环境提供的 NODE_PATH 加载，没有新增项目依赖）。网页开发服务中的 `/qa-motion.html` 是复验页，不是生产首页。
