# 灰线 GREYLINE

一款可直接在浏览器游玩的 2D 像素风格即时卡牌战争原型。战场宽 3,840 像素，视口宽 1,440 像素，支持横向移动。玩家对战 AI，用班组、坦克、直升机和支援技能攻占废弃村落。

## 操作

- 拖动空白战场、滚轮、A/D 或左右方向键移动视野。可点击或拖动小地图，或跳转到基地和我方前线。
- 点击「开始作战」。选择右下角手牌，再点击蓝色区域部署；也支持鼠标拖动。
- 火炮卡可指定任意位置。士气、补给、干扰选中后点击「立即下达」。
- 数字 1–6 选牌，左右方向键移动落点，回车确认；空格暂停，Esc 取消选择。
- 离开页面会自动暂停。作战手册与牌库查看也暂停战局。

## 规则

基地各有 1,000 生命，摧毁敌方指挥部获胜；4 分钟超时比较基地剩余生命。
开局 7 指挥点，每 2.8 秒恢复 1 点，上限 10；每 9 秒抽 1 张，手牌上限 6 张。18 张牌循环洗牌。
AI 使用同样的卡牌、抽牌和资源函数。

步兵班有 6 人，机枪班与重火力组各 5 人。每名士兵都是独立实体，拥有独立生命、目标、攻击计时、位置和动画状态。班组的面板生命与伤害表示全组总量。坦克和直升机各为一个单位。
炮弹产生可破坏且可通行的地形弹坑。士兵与车辆会跟随地面高度，在陡坡上减速；直升机无视地形。

## 美术与动画

背景按 640×214 的逻辑像素网格渲染，士兵动画使用 64×48 帧画布，其中直立角色按约 30×42 逻辑像素绘制，匍匐姿态保留完整身体长度；载具按 64×32 渲染。

全部素材用最近邻放大。美术采用正常成人比例和低饱和现代军服。
每个人有站立、行走、奔跑、攀墙、下蹲、趴下，以及开火、受击倒下的逐帧动画。每个人使用自己的动作时钟；机枪手和火箭兵在同一成人动作基础上装备对应武器。
坦克有履带帧与开炮后坐，直升机有旋翼帧；爆炸、尘土和弹道为实时粒子效果。

战场下方的步兵指令支持驻守、推进、奔跑、蹲行、卧倒。奔跑速度 ×1.7，蹲行速度 ×0.55、受到伤害 −15%，匍匐速度 ×0.25、受到伤害 −30%。完整矮墙会触发每名士兵各自的攀越；墙可被炮火摧毁。

## 项目

- `app/page.tsx`：交互、指挥台、手牌、音效与键盘操作。
- `game/engine.ts`：纯战斗模拟，可不依赖浏览器运行。
- `game/render.ts`：Canvas 战场与逐帧动画。
- `game/art.ts`：素材加载、帧提取、低分辨率像素渲染。
- `public/art/`：生成的像素素材。
- `tests/engine.test.mjs`：独立士兵、战斗、地形、资源、技能及完整对局模拟。

开发：`pnpm dev`；构建：`pnpm build`。
测试：`node --experimental-strip-types tests/engine.test.mjs`。

当前为本地状态的单人对 AI 原型，没有联网双人模式或存档。

前景使用泥土、岩石、草根剖面贴图，并以地形轮廓裁切；炮击挖去地表后露出内层土壤。枪弹为短曳光，炮弹保留弹体与尾迹，枪口和命中点有短促火光与扬尘。

验证包含独立战斗模拟与离屏 Canvas 素材、动画帧检查；浏览器交互和 WebMCP 调用尚未做自动化验证。
